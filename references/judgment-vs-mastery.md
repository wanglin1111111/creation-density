# 判断力 vs 熟练度：时间押注与季度体检

## 核心区分：押注判断力，不是熟练度

AI 洗牌后，时间投入分两类账：

| 类别 | 例子 | AI 时代走势 | 时间策略 |
|---|---|---|---|
| 熟练度 | 熟练操作工具、语法熟练、流程执行、模板化产出 | 被 AI 平权（门槛打掉，人人可得） | **不再投边际时间** |
| 判断力 | 问题定义、审美取舍、结果负责、验收标准 | 随创造密度复利增长（越做越准） | **堆时间** |

学历、绩点、名校、大厂依然重要，但已不能许诺一个确定的未来——它们本质是"熟练度与履历的确定性"，而 AI 加速了这种松动的部分。稀缺的是：在真实问题上做定义与取舍、并对结果负责的记录。

## 时间分配纪律

- **问题定义 + 验收结果的时间占比 ≥ 执行时间**（执行已大量交给 AI）
- 每次投入前先问：这一小时是在积累判断力（定义/取舍/负责），还是在积累熟练度（熟练操作）？后者超过一半 → 重新分配
- 判断力的积累只能来自**闭环的创造**：做完一件事、看过结果、承担过一次验收——刷题与听课不产生判断力

## 季度路径体检（三问）

每季度末做一次，答案写下来（不写=没体检）：

```markdown
# 路径体检 Q<季度>
1. 我这三个月的时间，押在了会不会被 AI 平权的地方？
   证据（时间去向明细）: ...
2. 这三个月闭环了几个可被他人直接使用的东西？
   清单 + 使用证据: ...
3. 沉淀了几个 prompt/模板（创造密度资产）？
   清单: ...
结论: 保持 / 下一季度挪 N% 时间到交付记录与作品积累
```

判读规则：
- 第 1 问答"是"（押在熟练度）且第 2 问闭环数 < 2 → 强制调整：下一季度挪时间到能积累交付记录的事
- 第 3 问为 0 → 复盘环节（六步第 ⑥ 步）系统性缺失，先修工作流再谈押注

## "一个人 = 一个小团队"的正确顺序

AI 让单人产能成立，但顺序不可反：

```
单人用 AI 跑通密度（同样时间交付更多）
  → 产出可验证结果（交付记录 + 作品 + 使用证据）
  → 再争取资源 / 拉人 / 谈机会
```

顺序反了 = **拿热情换资源**，大多换不到。可验证结果是谈判筹码，热情不是。
