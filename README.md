# creation-density

AI 时代创造密度与闭环工作流技能：换考核口径（追闭环数不追开题数）、六步工作流（真实问题→最小可交付件→AI 初稿→人判断取舍校验→交付→复盘沉淀）、真实问题驱动、单人先跑通、押注判断力、季度路径体检。

一句话：**AI 把创造的门槛打掉了，该押注的不再是学历/大厂这条确定性路径，而是"把一件事真正做成"的创造密度。**

## 理念底座

- 王佳梁（触宝科技创始人，2018 纽交所上市、服务全球超 2 亿用户；上海交大课余创业学院院长）AI Native 孵化器 HF0
- 承接"被真实问题击中时'我想为它做点什么'的冲动"，而非单纯创业热情
- ⚠️ 付费孵化/全职创业前先核实成本与机会成本，别照单全收

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| 开题成瘾：开了很多头没做成一个 | 考核口径只追"闭环了多少"（可被他人直接使用的产物数），开题不计分 |
| 选题靠热情，死在中途 | 问题型选题：本周重复 ≥3 次的一件具体事，答得出被谁击中 |
| "我在研究 AI"式无限期状态 | 强制转成有交付物的任务；转不了 = 不值得投 |
| 交付自嗨（做出来没人用） | 闭环证据字段必填：他人使用/接收记录 |
| 每个项目从零开始 | 复盘强制沉淀 prompt/模板，密度才复利 |
| 时间押错地方（押熟练度） | 季度路径体检：押在会被 AI 平权的地方 → 挪时间到判断力积累 |
| 拿热情换资源 | 单人先跑通 M1-M3 里程碑，再组队/融资/谈机会 |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```
